## Grade rules

PHAM-001 is an oversized cropped bomber. Horizontal volume grades more than vertical length so the silhouette stays cropped rather than simply scaling proportionally.

| Point of measure | Grade per adjacent size | Reason |
| --- | ---: | --- |
| Chest width, flat | 2.0 | +4.0 cm total chest circumference per size |
| Shoulder width | 1.0 | Preserve dropped shoulder without over-widening |
| Body length | 1.0 | Preserve the cropped proportion |
| Sleeve length | 1.0 | Track body scale while keeping sleeve geometry controlled |
| Shoulder drop | 0.5 | Small vertical grade only |
| Armhole | 2.0 | Maintain mobility and sleeve/armhole balance |
| Bicep, flat | 1.0 | Preserve sleeve volume across sizes |
| Cuff width, flat | 0.25 | Rib cuff should not balloon with size |
| Bottom hem circumference | 4.0 | Track body/chest grade |
| Collar length / height | 0.0 | Preserve the design component; factory must reconcile neckline seam length separately |

## Customer-facing fit logic

The tech pack labels the silhouette oversized and cropped. PHAM Fit therefore uses chest ease as the primary sizing signal and shoulder as a secondary dropped-shoulder check.

Target total chest ease:

- CLOSE: 24 cm
- INTENDED: 30 cm
- RELAXED: 36 cm

Target shoulder ease:

- CLOSE: 7 cm
- INTENDED: 9 cm
- RELAXED: 11 cm

At INTENDED fit, the starting body-chest centers are:

- M: 100 cm
- L: 104 cm
- XL: 108 cm
- XXL: 112 cm

Customer-facing starting bands are deliberately narrow around those centers:

- M: 98–101 cm
- L: 102–105 cm
- XL: 106–109 cm
- XXL: 110–114 cm

A customer below the M band can still wear M with more design ease. A customer above the XXL band can still fit XXL with less design ease, subject to shoulder, armhole, sleeve and personal preference.

Height and weight are context only; they do not override chest/shoulder fit.

## Production gate

Before bulk cutting:

1. Factory grades the actual XL pattern to M/L/XXL using the grade rules.
2. PHAM checks pattern seam compatibility, especially sleeve cap ↔ armhole, neckline ↔ collar and hem components.
3. Factory returns graded measurement spec.
4. PHAM reconciles any differences against this proposal.
5. At minimum, physically fit-check XL plus one non-base size before approving the full size run.

Do not treat derived M/L/XXL values as factory-verified measurements until this gate is complete.
